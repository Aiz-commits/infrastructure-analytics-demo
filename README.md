# Infrastructure Analytics Demo
### Construction Project Monitoring & Financial Audit System

**An interactive Python application for construction project monitoring, financial verification, technical quantity analysis, and automated reporting.**

## Live Interactive Dashboard

🚀 [Launch the Interactive Dashboard](https://infrastructure-analytics-demo-4mfqpmmrpqmf9hamcevdrf.streamlit.app)

Explore financial monitoring, automated audits, technical quantity analysis, Excel document processing, and downloadable reports.

*All demonstration data is synthetic.*

## Project Overview

This application was developed as part of a university internship project in Business Administration.

The objective was to explore how Python and data analytics can support construction project management by improving financial visibility, automating calculation checks, and organizing technical information.

**Public demonstration notice:** All financial amounts, technical quantities, project identifiers, and sample Excel documents provided in this repository are synthetic. No confidential company documents are included in the demonstration dataset.

## Key Features

**1. Financial Overview**
- Interactive visualization of construction expenditures.
- Cumulative financial monitoring.
- Indicative contract valuation metrics.

**2. Financial Audit**
- Financial continuity checks between successive payment statements.
- Retention, VAT, and TTC verification.
- Identification of discrepancies requiring further investigation.

**3. Technical Monitoring**
- Monitoring of construction work quantities.
- Category-based filtering for roadworks and drainage systems.
- Validation status charts and review alerts.

**4. Document Analysis**
- Excel worksheet import and preview.
- Automated financial extraction and arithmetic verification.
- Multi-document comparison and financial continuity analysis.

**5. Report Center**
- Downloadable financial and technical analysis reports in Excel format.

## Technologies

- **Python** — Application logic and financial calculations
- **Streamlit** — Interactive web dashboard
- **Pandas** — Data processing and analysis
- **OpenPyXL** — Excel reading and report generation
- **Altair** — Data visualization

## Run Locally

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Launch the dashboard:

```bash
streamlit run app.py
```

Then open the local address displayed in your terminal.

## Demonstration Data

The repository includes fictional construction payment statements and generated Excel audit reports for testing the application.

The included data demonstrates the application's functionality and does not represent the financial performance of an actual construction project.
